========================================================================
     2D TERMINAL BALLISTICS & ARMOR SIMULATOR (v16) — ИНСТРУКЦИЯ ДЛЯ WINDOWS
========================================================================

ВАРИАНТ 1: ЗАПУСК ЧЕРЕЗ PYTHON (БЕЗ СБОРКИ)
--------------------------------------------
1. Скачайте и установите Python 3.10, 3.11 или 3.12 с официального сайта:
   https://www.python.org/downloads/
   *ОБЯЗАТЕЛЬНО* отметьте галочку: "Add Python to PATH" во время установки!

2. Откройте командную строку (cmd) в папке с проектом:
   - В проводнике кликните в адресную строку папки, введите `cmd` и нажмите Enter.

3. Установите библиотеки:
   pip install -r requirements.txt

4. Запустите симулятор:
   python main.py


ВАРИАНТ 2: СБОРКА В ОДИН КЛИК В ArmorSim_v16.exe
-----------------------------------------------
1. Дважды кликните по файлу `build_windows.bat`.
2. Скрипт сам скачает PyInstaller, соберет исполняемый `.exe` и поместит его в папку `release/ArmorSim_v16.exe`.


УПРАВЛЕНИЕ:
--------------------------------------------
- [Пробел] (Space) — Произвести выстрел
- [R] — Сбросить симуляцию / очистить разрушения и экипаж
- [ЛКМ на пушке / линии прицеливания] — Регулировка высоты и угла прицеливания
- [ЛКМ Перетаскивание плиты] — Смещение бронеплиты по осям X / Y
- [ЛКМ Перетаскивание модулей] — Свободное позиционирование экипажа в боевом отделении
- [ПКМ или клавиша Del] — Удалить выбранный модуль экипажа
- Слайдер "Slow-Motion Speed" — Изменение скорости времени (с сохранением истинной баллистики частиц)
